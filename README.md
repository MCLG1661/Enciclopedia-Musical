## 💼 Sobre o Projeto

A **Enciclopédia Musical** é uma aplicação web desenvolvida para organizar e disponibilizar informações sobre diferentes dimensões da música, reunindo artistas, bandas, DJs, estilos, décadas e festivais em uma experiência de pesquisa e exploração de conteúdo.

O projeto utiliza uma base de conhecimento estruturada em **JSON**, enquanto **JavaScript** é responsável pela pesquisa, filtragem e apresentação dinâmica das informações na interface.

A aplicação teve origem na **Imersão Dev da Alura** e foi expandida como projeto de estudo e portfólio, aplicando conceitos de desenvolvimento front-end, manipulação de dados e construção de interfaces interativas.

---

## 🎯 Objetivo

Construir uma aplicação capaz de transformar uma base estruturada de informações musicais em uma experiência simples e interativa de consulta.

O projeto procura conectar três componentes principais:

```text
Base de conhecimento
        ↓
Pesquisa e filtragem
        ↓
Exploração do conteúdo
```

A proposta é permitir que diferentes dimensões da história e da cultura musical sejam pesquisadas a partir de uma única interface.

---

## ✨ Funcionalidades

### 🔍 Pesquisa e exploração musical

A aplicação permite pesquisar e explorar conteúdos relacionados a:

- décadas;
- estilos musicais;
- bandas;
- artistas;
- DJs;
- festivais.

### 📚 Base de conhecimento

As informações são armazenadas em uma estrutura **JSON**, utilizada pela aplicação como fonte para pesquisa e recuperação dos conteúdos.

### 🎼 Resultados dinâmicos

O JavaScript processa as consultas realizadas pelo usuário, filtra os dados disponíveis e apresenta os resultados encontrados na interface.

### 🗂️ Cards de conteúdo

Os resultados são organizados visualmente em cards, facilitando a leitura e a exploração das informações musicais.

### 📱 Interface responsiva

A aplicação utiliza princípios de **Responsive Web Design**, permitindo adaptação da interface a diferentes tamanhos de tela.

## 🔄 Como a Aplicação Funciona

```text
Usuário
   ↓
Campo de pesquisa
   ↓
JavaScript
   ↓
Consulta à base JSON
   ↓
Filtragem dos dados
   ↓
Renderização dos resultados
   ↓
Exploração do conteúdo
```

Essa estrutura separa a **base de conhecimento**, a **lógica de pesquisa** e a **apresentação dos resultados**, tornando o funcionamento da aplicação mais organizado e compreensível.
